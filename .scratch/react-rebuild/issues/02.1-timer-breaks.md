# 02.1: Breaks during a timer session

**Parent:** 02 (Timer page)

**What to build:** While a timer is running, the user can log a break (requirement R5). The break interrupts the session, and may become its own separate recorded time entry (e.g. a labelled "break" entry), matching the legacy app. The parent session's entry keeps its `breaks` data.

Legacy reference: `frontend/js/controllers/timer-controller.js` — `handleLogBreak` (~line 208) opens `break-modal.js`; on confirm the break is saved as its own time entry via a break task (~lines 547–579), and the active entry carries a `breaks` array (already present in the TimeEntry API shape — the React fixtures include `breaks: []`).
