# 05.5: See a project's time entries

**Parent:** 05 (Projects & Workspace)

**What to build:** A project row shows a total but not what makes it up. Its ⋮
menu gets an entry that opens a modal listing every time entry logged against
that project — what, when, how long.

Needs a backend filter: `GET /api/time-entries/` takes no query parameters today,
so there is no way to ask for one project's entries.

**Blocked by:** 05.4 (Associate a time entry with a project)

**Status:** done (2026-09-13)

- [x] Backend: GET /api/time-entries/ filters by `project` (and by `task`)
- [x] Project ⋮ menu opens the modal
- [x] Modal lists the project's entries: task title, date, start–end, duration
- [x] Entries are newest first and paginate (or load more) past the first page
- [x] Modal closes on Escape, on backdrop click, and returns focus to the trigger
- [x] Empty state when the project has no entries yet
