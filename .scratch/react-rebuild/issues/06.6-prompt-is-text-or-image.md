# 06.6: The prompt is text or an image, and it isn't a "title"

**Parent:** 06 (Study page core)

**What to build:** The prompt side is still modelled as a required "Title" text
field with an optional image hanging off it. But a study item is a two-sided
card and the prompt side obeys the same rule as the answer: it is *one* thing —
text or an image. When the prompt is an image, the image is the prompt, and
there is no text to show.

The word "title" goes with it; the field is the **Prompt** (the backend field has
always been called `prompt`, and it pairs with Answer).

**Blocked by:** 06.3 (answer is text or an image) — done

**Status:** done (2026-09-13)

- [x] The form offers Text or Image for the prompt, never both, mirroring Answer
- [x] "Title" is gone from the UI; the field reads Prompt
