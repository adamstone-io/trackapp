# 06.2: Second image on study items (prompt + answer note)

**Parent:** 06 (Study page core)

**What to build:** A study item can carry two images, not one: an image for the
prompt (front) and an image for the answer note. Ticket 06 read "optional image"
(singular) and only surfaced the `image` field; the backend has had a second
`note_image` field with its own endpoints all along (R24 / spec story 32 say
"images", plural). Both must be addable, replaceable, removable, and visible.

**Blocked by:** 06 (Study page core) — done

**Status:** done (2026-09-13)

Backend is already complete — no API work expected:
`POST /study-items/{id}/upload_image/` (form field `image`),
`DELETE /study-items/{id}/remove_image/`,
`POST /study-items/{id}/upload_note_image/` (form field `note_image`),
`DELETE /study-items/{id}/remove_note_image/`.
The serializer already returns `image_url` and `note_image_url`.

- [x] Add form takes a prompt image and a note image, either/both optional
- [x] Edit form can replace or remove each image independently
- [x] Both images render on the item row — prompt image with the title, note
      image with the notes
- [x] Partial-save semantics from ticket 06 extend to two legs: a failed image
      never rolls back the saved row, and the toast names which image failed
- [x] Optimistic UI with rollback + error toast on the non-image legs
