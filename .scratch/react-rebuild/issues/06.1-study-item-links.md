# 06.1: Study item links

**Parent:** 06 (Study page core)

**What to build:** Each study item has a links page where the user can connect it to other study items (requirements R29a, R29b). Links are bidirectional: linking A to B makes each visible from the other, and a linked item is navigable directly from the links page of the item it is linked to.

**Blocked by:** 06 (Study page core)

**Status:** ready-for-agent

- [ ] Links view reachable from a study item
- [ ] Add a link to another study item (search/select from existing items)
- [ ] Link is bidirectional: appears on both items
- [ ] Clicking a linked item navigates to that item
- [ ] Remove a link (removes it from both sides)
- [ ] Optimistic UI with rollback + error toast
