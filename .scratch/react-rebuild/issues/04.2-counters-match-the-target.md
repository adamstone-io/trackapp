# 04.2: A habit shows only the counters it is aimed at

**Parent:** 04 (Habits page)

**What to build:** Every habit row shows all three counters — daily, weekly,
monthly — whether or not the habit has a target for that period. A daily habit's
weekly and monthly tallies are noise; a monthly habit doesn't need a daily one.
Show only the periods the habit actually targets.
