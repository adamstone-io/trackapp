# 06.3: Study reveals the answer; an answer is text or an image, not both

**Parent:** 06 (Study page core)

**What to build:** A study item is a two-sided card. The row shows only the
prompt side (title, category, prompt image); the answer side stays hidden until
the user presses Study. Pressing Study again — once they're done studying it —
logs the study interaction and hides the answer again.

The answer side is *one* thing: either a text note or an image. The UI enforces
that (the backend keeps both fields, and legacy rows that already hold both are
left alone until the user makes a choice).

Also: the add/edit form's fields currently share rows and stretch to the row's
height. Each field belongs on its own row.

**Blocked by:** 06.2 (prompt + note images) — done
