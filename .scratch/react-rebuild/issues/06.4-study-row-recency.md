# 06.4: Creation date and recency on each study row

**Parent:** 06 (Study page core)

**What to build:** A study row should say, at a glance, how stale it is: when the
item was created, and how long since it was last primed and last studied — days
since, not just a raw date ("20 days ago" reads faster than "24 Aug 2026").
