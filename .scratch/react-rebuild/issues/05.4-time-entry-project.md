# 05.4: Associate a time entry with a project

**Parent:** 05 (Projects & Workspace)

**What to build:** Nothing in the app lets the user say which project a piece of
tracked time belongs to. A time entry points at a task, and only the task's
project connects it to a project at all — but the timer and the manual entry form
never set one, so every task the web app creates is unassigned and project totals
only ever count time logged through the legacy app.

The user picks a project when logging time, and can set or change the project of
an entry already in the day log.
